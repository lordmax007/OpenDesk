# OpenDesk
OpenDesk: acesso remoto próprio, feito do zero. Agente para Windows em Rust e acesso pelo Chrome, sem instalar nada. Vídeo H.264 por hardware a 1080p60 via WebRTC, controle de mouse e teclado, arquivos e chat, ID fixo, senha protegida com Argon2 e modo administrador (UAC, tela de login, Ctrl+Alt+Del).
